# Chita

Downloads and updates for [Chita](https://github.com/decomponendiscifris/chita-releases/releases),
a fast file manager for macOS 15 and later.

## Install

Download the latest `Chita-<version>.dmg` from
[Releases](https://github.com/decomponendiscifris/chita-releases/releases/latest), open it, and
drag Chita to Applications. Chita asks for Full Disk Access the first time it starts, so it can
index and search every folder.

## Updates

Chita checks for updates by itself (Chita › Check for Updates…, and Settings › General). It reads
the update feed this repository publishes at
`https://decomponendiscifris.github.io/chita-releases/appcast.xml`, and installs an update only
when it is signed with Chita's own update key.

## Problems and ideas

[Open an issue](https://github.com/decomponendiscifris/chita-releases/issues/new/choose): a short
form asks what happened, how to make it happen again and which Chita and macOS you have.
